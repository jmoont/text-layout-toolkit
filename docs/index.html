Text & Layout Toolkit

Text & Layout Toolkit for Canva

A Canva app with a set of tools for things Canva can't do on its own:

  • Paragraph spacing — add even, adjustable spacing between paragraphs in a text box.
  • Wrap text around an image — flow a paragraph around an overlapping image.
  • QR code — generate an editable, vector QR code from any URL.

Everything runs locally inside the Canva editor. The app has no backend and never sends your content anywhere except Canva itself.
