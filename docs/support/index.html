Paragraph spacing

How do I add spacing between paragraphs?

Select a text box on your canvas, open the app, choose Paragraph spacing, set the gap size with the slider (or type an exact value), then click Apply spacing. The app inserts an evenly-sized blank line between each paragraph.

Nothing happens when I click Apply.

The tool needs a text box with at least two paragraphs (separated by a line break). If only one paragraph is selected there's no gap to create. Make sure the text box — not just the page — is selected.

Can I change the spacing later?

Yes. Re-run the tool with a different size and it re-sizes the existing blank lines. Canva's normal undo (Ctrl/Cmd+Z) also reverts the change.

Wrap text around an image

How do I wrap text around an image?

Place a text box so it overlaps an image, open the app, choose Wrap text around image, optionally set which side the image is on and the gap, then click Wrap text. The app adds line breaks so the text flows around the image.

The wrap isn't perfect.

Canva doesn't let apps measure text, so wrapping is estimated and may need a nudge — adjust the gap, switch the side, move the image, and re-run. It works best with a single rectangular image beside a left- or right-aligned paragraph. Undo reverts it at any time.

It says it only works on fixed layouts.

Wrapping relies on element positions, which are only available in fixed-layout designs (presentations, social posts, flyers, and similar) — not in Canva Docs or whiteboards.

QR code

How do I add a QR code to my design?

Open the app, choose QR code, type or paste a URL, pick your foreground and background colors (or enable the transparent-background switch), then click Add QR code. The code is inserted at the top-left of your page — drag it where you'd like and resize from the corner handles.

The QR code won't scan. What's wrong?

  • Add a quiet zone. Most scanners need a margin of at least four modules of empty space around the code.
  • Use enough contrast. Dark foreground on a light background scans best. Very light colors or busy backgrounds behind a transparent QR can defeat the scanner.
  • Don't shrink it too small. Printed smaller than ~2 cm, many phone cameras can't lock onto the modules.
  • Test before publishing. Always scan with a real phone camera before exporting.

Can I resize the QR code without losing quality?

Yes. The QR is inserted as a vector SVG, so it stays crisp at any size.
